# Security policy

PumpGuard-AI is educational and research software. It must not make automated trip, shutdown, maintenance, alarm or safety decisions. Its score is not calibrated to equipment health or risk.

Do not paste credentials, private datasets or confidential operational logs into public issues.

Please report security vulnerabilities privately using GitHub private vulnerability reporting where enabled; otherwise establish a private channel with maintainers. Avoid posting exploit details publicly before a fix is available.
