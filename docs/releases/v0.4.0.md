# PumpGuard-AI v0.4.0 — Research Preview

**Experimental research software, not a validated industrial fault-diagnosis or safety system.** The repository's code is MIT licensed. This is the first integrated GitHub Release, marked as a prerelease.

## Included
- Deterministic, **synthetic** vibration demonstrations; time/spectral/envelope features and order analysis.
- Opt-in loader for locally downloaded Paderborn KAt bearing files, with provenance, physical-bearing group splits and transparent baselines.
- ESP multistage pump–well operating-point modelling, VSD frequency orders, sensor/Nyquist limits, typed SCADA and laboratory rig documentation.
- Optional `[ml]`: logistic regression and fixed-hyperparameter random forest assessed against the existing physics-based baselines.
- Synthetic experiment comparing random segment splitting with grouped splitting on unseen bearings/machines.

## Quality
PR-based CI passed for #9 (8/8 jobs), #10 (8/8) and #11 (9/9) on Linux, Windows and macOS. The tagged release is created only after **the v0.4.0 main-branch CI has passed**; its source, wheel and sdist are downloadable as release assets.

## Install
```bash
git clone https://github.com/ymesbah-blip/-PumpGuard-AI.git pumpguard-ai
cd pumpguard-ai
git checkout v0.4.0
python -m pip install -e ".[dev,ml]"
python -m pytest
pumpguard --version
pumpguard benchmark --synthetic --learned --out benchmark_preview
```

## Scientific limitations and data rights
**No original Paderborn MAT files were run when releasing this version.** No real-fault accuracy, early-warning lead-time, RUL or calibrated equipment safety threshold has been demonstrated. Synthetic classification results are *not* field performance.

Paderborn University KAt recordings use **CC BY-NC 4.0** with attribution, distinct from this project's MIT-licensed code; the dataset is **not redistributed**. Do not publish private operational data, and do not connect PumpGuard-AI directly to safety or shutdown systems.

PyPI publication is not enabled by default. It needs separate configuration of a PyPI Trusted Publisher and the `ENABLE_PYPI_PUBLISH` GitHub repository variable.
